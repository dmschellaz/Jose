# Redline Phase 1 (Manual Mode) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a menu bar Mac app that records a narrated walkthrough of a web app (screen keyframes, on-device transcript, clicks, browser URL, pen marks) and, on stop, writes `feedback.md` plus annotated PNGs and copies a paste-ready prompt for Claude Code.

**Architecture:** All logic that can be tested without the OS lives in a SwiftPM library, `RedlineCore`: timeline, geometry, compositing, segmentation, Markdown, the Claude client, the report builder, the session state machine and the pen-gesture detector. It's tested with `swift test`. The app target, `Redline`, is a thin AppKit/SwiftUI layer generated by XcodeGen. It implements `RedlineCore`'s service protocols with ScreenCaptureKit, SpeechAnalyzer, a CGEvent tap, AppleScript, and overlay `NSPanel`s.

**Tech Stack:** Swift 6.2, SwiftUI + AppKit, ScreenCaptureKit, Speech (`SpeechAnalyzer`/`SpeechTranscriber`), AVFoundation, ImageIO/CoreGraphics, Swift Testing, XcodeGen, [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts), Claude Messages API over `URLSession`.

**Spec:** `docs/superpowers/specs/2026-11-22-redline-feedback-app-design.md`. Read it before starting. This plan covers its §8 phase 1.

## Global Constraints

- macOS deployment target **26.0**, Apple Silicon. Swift tools version **6.2**, Swift 6 language mode.
- Full **Xcode** is required. The Command Line Tools alone can't compile SwiftUI's `@State` macros or provide a stable signing identity. This was verified on this machine.
- Bundle ID **`com.dmschellaz.redline`**, `LSUIElement = true` (no Dock icon), not sandboxed, hardened runtime on.
- No backend server, accounts, telemetry, cloud speech-to-text or video recording.
- API key is stored only in Keychain (service `com.dmschellaz.redline`, account `anthropic-api-key`).
- Claude API: `POST https://api.anthropic.com/v1/messages`, header `anthropic-version: 2026-10-21`. No `temperature`/`top_p`/`top_k`. No forced `tool_choice`, since it returns a 400 on Sonnet 5.5 and Opus 5.5; use structured outputs `output_config.format` instead. Send `fallbacks: "default"` with header `anthropic-beta: server-side-fallback-2026-07-01`. Check `stop_reason` for `refusal`/`max_tokens` before reading content.
- Report model is chosen in Settings between `claude-sonnet-5-5` (default) and `claude-opus-5-5`. Effort is `medium`.
- Default hotkeys: **⌃⌥F** toggles the session, **⌃⌥M** marks a moment, and the pen is drawn by holding **⌥ alone ≥ 150 ms**.
- Output root defaults to `~/Feedback`. Session folders are named `<slug>-yyyy-MM-dd-HHmm`.
- All stored coordinates are **global Quartz points** (origin at top-left of the primary display, y down).
- Images sent to the API are JPEG at most 1280 px wide; saved PNGs are at most 2560 px wide; at most 20 images per report request.

## Deviations from the spec (phase 1 only; spec updated to match)

1. **Report call:** structured outputs instead of a forced `write_report` tool (API constraint above).
2. **Capture:** keyframes are taken on events (click + 300 ms, sentence end, mark, pen release) and every 5 s. The 2 fps ring buffer is deferred to phase 2, where Live mode needs it.
3. **Cancel:** a **Cancel** button in the pill (click twice to confirm) and a menu item replace Esc. A global Esc would steal Esc from the app being reviewed.
4. **Voice processing** (echo cancellation) is enabled only in Chatty mode (phase 3), because on macOS it ducks other audio.
5. **Captions** aren't drawn into PNGs in phase 1. Only AI marks have captions, and those arrive in phase 2.
6. **Missing permission at start** opens the Setup window instead of an in-pill message.

```swift
import CoreGraphics

/// A display's frame in global Quartz points (origin top-left of the primary display, y down) and its backing scale.
public struct DisplayGeometry: Codable, Equatable, Sendable {
    public var id: UInt32
    public var frame: CGRect
    public var scale: Double

    public init(id: UInt32, frame: CGRect, scale: Double) {
        self.id = id
        self.frame = frame
        self.scale = scale
    }
}

/// Every conversion between coordinate spaces goes through here.
/// - global: Quartz points across all displays
/// - pixel: pixels of a full-resolution capture of one display
/// - imagePoint: pixels of an image of arbitrary size covering one display (e.g. downscaled for the API)
/// - local: points relative to one display's top-left (SwiftUI overlay space)
/// - cocoa: AppKit screen points (origin bottom-left of the primary display, y up)
public enum CoordinateMapper {
    public static func pixel(fromGlobal p: CGPoint, on d: DisplayGeometry) -> CGPoint {
        CGPoint(x: (p.x - d.frame.minX) * d.scale, y: (p.y - d.frame.minY) * d.scale)
    }

    public static func global(fromPixel p: CGPoint, on d: DisplayGeometry) -> CGPoint {
        CGPoint(x: p.x / d.scale + d.frame.minX, y: p.y / d.scale + d.frame.minY)
    }

    public static func imagePoint(fromGlobal p: CGPoint, imageSize: CGSize, on d: DisplayGeometry) -> CGPoint {
        CGPoint(x: (p.x - d.frame.minX) * imageSize.width / d.frame.width,
                y: (p.y - d.frame.minY) * imageSize.height / d.frame.height)
    }

    public static func global(fromImagePoint p: CGPoint, imageSize: CGSize, on d: DisplayGeometry) -> CGPoint {
        CGPoint(x: p.x * d.frame.width / imageSize.width + d.frame.minX,
                y: p.y * d.frame.height / imageSize.height + d.frame.minY)
    }

    public static func local(fromGlobal p: CGPoint, on d: DisplayGeometry) -> CGPoint {
        CGPoint(x: p.x - d.frame.minX, y: p.y - d.frame.minY)
    }

    public static func global(fromLocal p: CGPoint, on d: DisplayGeometry) -> CGPoint {
        CGPoint(x: p.x + d.frame.minX, y: p.y + d.frame.minY)
    }

    public static func quartz(fromCocoa p: CGPoint, primaryHeight: Double) -> CGPoint {
        CGPoint(x: p.x, y: primaryHeight - p.y)
    }

    public static func display(containing p: CGPoint, in displays: [DisplayGeometry]) -> DisplayGeometry? {
        displays.first { $0.frame.contains(p) }
    }
}
```

`Packages/RedlineCore/Sources/RedlineCore/Annotation/Annotation.swift`:
```swift
import CoreGraphics
import Foundation

public enum AnnotationShape: Codable, Equatable, Sendable {
    case circle(center: CGPoint, radius: Double)
    case rect(CGRect)
    case arrow(from: CGPoint, to: CGPoint)
    case highlight(CGRect)
    case stroke([CGPoint])

    /// Maps every point through `f`; lengths (radius) are multiplied by `lengthScale`.
    public func mapped(_ f: (CGPoint) -> CGPoint, lengthScale: Double) -> AnnotationShape {
        func mapRect(_ r: CGRect) -> CGRect {
            let a = f(CGPoint(x: r.minX, y: r.minY))
            let b = f(CGPoint(x: r.maxX, y: r.maxY))
            return CGRect(x: min(a.x, b.x), y: min(a.y, b.y), width: abs(b.x - a.x), height: abs(b.y - a.y))
        }
        switch self {
        case let .circle(center, radius): return .circle(center: f(center), radius: radius * lengthScale)
        case let .rect(r): return .rect(mapRect(r))
        case let .arrow(from, to): return .arrow(from: f(from), to: f(to))
        case let .highlight(r): return .highlight(mapRect(r))
        case let .stroke(points): return .stroke(points.map(f))
        }
    }
}

public enum AnnotationAuthor: String, Codable, Sendable {
    case user, ai
}

public struct Annotation: Codable, Equatable, Sendable, Identifiable {
    public var id: UUID
    /// Points are global Quartz points.
    public var shape: AnnotationShape
    public var caption: String?
    public var author: AnnotationAuthor
    /// Seconds since session start.
    public var createdAt: Double
    public var displayID: UInt32

    public init(id: UUID = UUID(), shape: AnnotationShape, caption: String?, author: AnnotationAuthor, createdAt: Double, displayID: UInt32) {
        self.id = id
        self.shape = shape
        self.caption = caption
        self.author = author
        self.createdAt = createdAt
        self.displayID = displayID
    }
}

import Foundation

public enum Slug {
    /// Lowercase, alphanumeric words joined by "-", first `maxWords` words. Returns "item" if nothing is left.
    public static func make(_ s: String, maxWords: Int = 3) -> String {
        let words = s.lowercased()
            .components(separatedBy: CharacterSet.alphanumerics.inverted)
            .filter { !$0.isEmpty }
            .prefix(maxWords)
        return words.isEmpty ? "item" : words.joined(separator: "-")
    }
}

public struct SessionFolder: Sendable, Equatable {
    public let url: URL

    public init(url: URL) { self.url = url }

    public var rawURL: URL { url.appending(path: "raw", directoryHint: .isDirectory) }
    public var feedbackURL: URL { url.appending(path: "feedback.md") }
    public var documentURL: URL { url.appending(path: "session.json") }

    /// "localhost-3000" for http://localhost:3000/…, "myapp-com" for https://www.myapp.com, "session" otherwise.
    public static func slug(fromURL string: String?) -> String {
        guard let string, let comps = URLComponents(string: string), var host = comps.host, !host.isEmpty else {
            return "session"
        }
        if host.hasPrefix("www.") { host.removeFirst(4) }
        let base = comps.port.map { "\(host)-\($0)" } ?? host
        return Slug.make(base, maxWords: 4)
    }

    public static func folderName(slug: String, date: Date, timeZone: TimeZone = .current) -> String {
        let f = DateFormatter()
        f.locale = Locale(identifier: "en_US_POSIX")
        f.timeZone = timeZone
        f.dateFormat = "yyyy-MM-dd-HHmm"
        return "\(slug)-\(f.string(from: date))"
    }

    /// Creates `<root>/<slug>-<date>[-N]/raw/`.
    public static func create(root: URL, slug: String, date: Date, timeZone: TimeZone = .current) throws -> SessionFolder {
        let fm = FileManager.default
        try fm.createDirectory(at: root, withIntermediateDirectories: true)
        let url = uniqueURL(root: root, name: folderName(slug: slug, date: date, timeZone: timeZone))
        let folder = SessionFolder(url: url)
        try fm.createDirectory(at: folder.rawURL, withIntermediateDirectories: true)
        return folder
    }

    /// Moves the folder to a name built from `slug`. Returns self if the name is unchanged.
    public func renamed(slug: String, date: Date, timeZone: TimeZone = .current) throws -> SessionFolder {
        let name = Self.folderName(slug: slug, date: date, timeZone: timeZone)
        if url.lastPathComponent == name { return self }
        let target = Self.uniqueURL(root: url.deletingLastPathComponent(), name: name)
        try FileManager.default.moveItem(at: url, to: target)
        return SessionFolder(url: target)
    }

    private static func uniqueURL(root: URL, name: String) -> URL {
        var candidate = root.appending(path: name, directoryHint: .isDirectory)
        var n = 2
        while FileManager.default.fileExists(atPath: candidate.path) {
            candidate = root.appending(path: "\(name)-\(n)", directoryHint: .isDirectory)
            n += 1
        }
        return candidate
    }
}

import CoreGraphics
import Foundation
import ImageIO
import UniformTypeIdentifiers

public enum ImageFileError: Error {
    case cannotCreateDestination, cannotFinalize
}

public enum ImageFiles {
    public static func writePNG(_ image: CGImage, to url: URL) throws {
        guard let dest = CGImageDestinationCreateWithURL(url as CFURL, UTType.png.identifier as CFString, 1, nil) else {
            throw ImageFileError.cannotCreateDestination
        }
        CGImageDestinationAddImage(dest, image, nil)
        guard CGImageDestinationFinalize(dest) else { throw ImageFileError.cannotFinalize }
    }

    public static func load(_ url: URL) -> CGImage? {
        guard let src = CGImageSourceCreateWithURL(url as CFURL, nil) else { return nil }
        return CGImageSourceCreateImageAtIndex(src, 0, nil)
    }

    /// Returns the image unchanged if it is already at most `maxWidth` wide.
    public static func downscaled(_ image: CGImage, maxWidth: Int) -> CGImage {
        guard image.width > maxWidth else { return image }
        let w = maxWidth
        let h = max(1, Int((Double(image.height) * Double(maxWidth) / Double(image.width)).rounded()))
        guard let ctx = CGContext(data: nil, width: w, height: h, bitsPerComponent: 8, bytesPerRow: 0,
                                  space: CGColorSpace(name: CGColorSpace.sRGB)!,
                                  bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue) else { return image }
        ctx.interpolationQuality = .high
        ctx.draw(image, in: CGRect(x: 0, y: 0, width: w, height: h))
        return ctx.makeImage() ?? image
    }

    public static func jpegData(_ image: CGImage, maxWidth: Int, quality: Double = 0.8) -> Data? {
        let data = NSMutableData()
        guard let dest = CGImageDestinationCreateWithData(data, UTType.jpeg.identifier as CFString, 1, nil) else { return nil }
        let props = [kCGImageDestinationLossyCompressionQuality: quality] as CFDictionary
        CGImageDestinationAddImage(dest, downscaled(image, maxWidth: maxWidth), props)
        guard CGImageDestinationFinalize(dest) else { return nil }
        return data as Data
    }
}

import CoreGraphics
import Foundation

public enum Palette {
    public static let user = CGColor(srgbRed: 1, green: 0.23, blue: 0.19, alpha: 1)
    public static let ai = CGColor(srgbRed: 0, green: 0.48, blue: 1, alpha: 1)
    public static let highlight = CGColor(srgbRed: 1, green: 0.85, blue: 0, alpha: 0.35)
}

public enum AnnotationCompositor {
    /// Draws `annotations` (global points) onto `image`, a capture covering `display`.
    public static func compose(image: CGImage, display: DisplayGeometry, annotations: [Annotation]) -> CGImage? {
        let w = image.width, h = image.height
        guard let ctx = CGContext(data: nil, width: w, height: h, bitsPerComponent: 8, bytesPerRow: 0,
                                  space: CGColorSpace(name: CGColorSpace.sRGB)!,
                                  bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue) else { return nil }
        ctx.draw(image, in: CGRect(x: 0, y: 0, width: w, height: h))
        // Switch to a top-left origin so pixel coordinates match the capture.
        ctx.translateBy(x: 0, y: CGFloat(h))
        ctx.scaleBy(x: 1, y: -1)

        let size = CGSize(width: w, height: h)
        let toPixel: (CGPoint) -> CGPoint = { CoordinateMapper.imagePoint(fromGlobal: $0, imageSize: size, on: display) }
        let pixelsPerPoint = Double(w) / display.frame.width
        ctx.setLineWidth(max(3, 2 * pixelsPerPoint))
        ctx.setLineCap(.round)
        ctx.setLineJoin(.round)

        for a in annotations where a.displayID == display.id {
            let color = a.author == .user ? Palette.user : Palette.ai
            ctx.setStrokeColor(color)
            switch a.shape.mapped(toPixel, lengthScale: pixelsPerPoint) {
            case let .circle(c, r):
                ctx.strokeEllipse(in: CGRect(x: c.x - r, y: c.y - r, width: 2 * r, height: 2 * r))
            case let .rect(r):
                ctx.stroke(r)
            case let .highlight(r):
                ctx.setFillColor(Palette.highlight)
                ctx.fill(r)
            case let .arrow(from, to):
                drawArrow(ctx, from: from, to: to, headLength: 14 * pixelsPerPoint)
            case let .stroke(points):
                guard let first = points.first else { continue }
                ctx.beginPath()
                ctx.move(to: first)
                for p in points.dropFirst() { ctx.addLine(to: p) }
                ctx.strokePath()
            }
        }
        return ctx.makeImage()
    }

    private static func drawArrow(_ ctx: CGContext, from: CGPoint, to: CGPoint, headLength: Double) {
        let angle = atan2(to.y - from.y, to.x - from.x)
        ctx.beginPath()
        ctx.move(to: from)
        ctx.addLine(to: to)
        for side in [-1.0, 1.0] {
            let a = angle + .pi + side * .pi / 7
            ctx.move(to: to)
            ctx.addLine(to: CGPoint(x: to.x + headLength * cos(a), y: to.y + headLength * sin(a)))
        }
        ctx.strokePath()
    }
}

  - `struct Moment: Codable, Equatable, Sendable { var id: Int; var start: Double; var end: Double; var sentences: [SentenceRef]; var url: String?; var userMarks: [Annotation]; var aiMarks: [Annotation]; var clickTimes: [Double]; var keyframe: KeyframeRef?; var text: String }`. `id` is 1-based.

Rules (spec §4.1 ReportBuilder steps 1–2):
- A new moment starts when the gap between sentences is ≥ 4 s, on a URL change, or on ⌃⌥M (`momentMarked`, which closes the current moment).
- If there are no sentences at all, each user mark or `momentMarked` becomes its own moment.
- Each user mark, AI mark and click goes to the nearest moment by distance to its `[start, end]` range. On a tie, the earlier moment wins.
- A moment's URL is the latest `urlChanged` with `t <= start + 1`, falling back to the first URL seen.
- The keyframe anchor is the latest mark's time, else the latest click + 0.3 s, else the moment's midpoint. The closest keyframe to the anchor wins; on a tie, the later one.

import Foundation

public struct SentenceRef: Codable, Equatable, Sendable {
    public var id: UUID
    public var text: String
    public var start: Double
    public var end: Double
}

public struct Moment: Codable, Equatable, Sendable {
    public var id: Int
    public var start: Double
    public var end: Double
    public var sentences: [SentenceRef]
    public var url: String?
    public var userMarks: [Annotation] = []
    public var aiMarks: [Annotation] = []
    public var clickTimes: [Double] = []
    public var keyframe: KeyframeRef?

    public var text: String { sentences.map(\.text).joined(separator: " ") }

    public init(id: Int, start: Double, end: Double, sentences: [SentenceRef]) {
        self.id = id
        self.start = start
        self.end = end
        self.sentences = sentences
    }
}

public enum MomentSegmenter {
    public static let gap: Double = 4

    public static func segment(_ events: [TimelineEvent]) -> [Moment] {
        let sorted = events.sorted { $0.time < $1.time }

        // 1. Group sentences.
        var groups: [[SentenceRef]] = []
        var current: [SentenceRef] = []
        func close() {
            if !current.isEmpty { groups.append(current); current = [] }
        }
        for e in sorted {
            switch e {
            case let .sentence(id, text, start, end):
                if let last = current.last, start - last.end >= gap { close() }
                current.append(SentenceRef(id: id, text: text, start: start, end: end))
            case .urlChanged, .momentMarked:
                close()
            default:
                break
            }
        }
        close()

        var moments = groups.enumerated().map { i, g in
            Moment(id: i + 1, start: g.first!.start, end: g.last!.end, sentences: g)
        }

        // 2. No speech at all: one moment per explicit mark.
        if moments.isEmpty {
            let anchors: [Double] = sorted.compactMap { e in
                switch e {
                case let .userMark(a): return a.createdAt
                case let .momentMarked(t): return t
                default: return nil
                }
            }
            moments = anchors.enumerated().map { i, t in Moment(id: i + 1, start: t, end: t, sentences: []) }
        }
        guard !moments.isEmpty else { return [] }

        // 3. Attach marks and clicks to the nearest moment.
        func nearest(_ t: Double) -> Int {
            moments.indices.min { distance(t, moments[$0]) < distance(t, moments[$1]) }!
        }
        var urls: [(url: String, t: Double)] = []
        var keyframes: [KeyframeRef] = []
        for e in sorted {
            switch e {
            case let .userMark(a):
                let i = nearest(a.createdAt)
                moments[i].userMarks.append(a)
            case let .aiAnnotation(_, anns, _):
                for a in anns {
                    let i = nearest(a.createdAt)
                    moments[i].aiMarks.append(a)
                }
            case let .click(_, _, t):
                let i = nearest(t)
                moments[i].clickTimes.append(t)
            case let .urlChanged(url, _, t): urls.append((url, t))
            case let .keyframe(ref, _): keyframes.append(ref)
            default: break
            }
        }

        // 4. URL and keyframe per moment.
        for i in moments.indices {
            moments[i].url = urls.last(where: { $0.t <= moments[i].start + 1 })?.url ?? urls.first?.url
            moments[i].keyframe = KeyframeSelector.select(for: moments[i], from: keyframes)
        }
        return moments
    }

    static func distance(_ t: Double, _ m: Moment) -> Double {
        if t < m.start { return m.start - t }
        if t > m.end { return t - m.end }
        return 0
    }
}

public enum KeyframeSelector {
    public static func anchorTime(for m: Moment) -> Double {
        if let t = (m.userMarks + m.aiMarks).map(\.createdAt).max() { return t }
        if let t = m.clickTimes.max() { return t + 0.3 }
        return (m.start + m.end) / 2
    }

    public static func select(for m: Moment, from keyframes: [KeyframeRef]) -> KeyframeRef? {
        let anchor = anchorTime(for: m)
        return keyframes.min { a, b in
            let da = abs(a.t - anchor), db = abs(b.t - anchor)
            return da < db || (da == db && a.t > b.t)
        }
    }
}

public struct TranscriptLine: Equatable, Sendable {
    public var t: Double
    public var text: String
    public init(t: Double, text: String) {

        self.text = text
    }

public enum TranscriptBuilder {
    public static func lines(_ events: [TimelineEvent]) -> [TranscriptLine] {
        events.sorted { $0.time < $1.time }.compactMap { e in
            switch e {
            case let .sentence(_, text, start, _): return TranscriptLine(t: start, text: text)
            case let .click(_, _, t): return TranscriptLine(t: t, text: "(click)")
            case let .urlChanged(url, _, t): return TranscriptLine(t: t, text: "(opened \(FallbackReport.pathOf(url)))")
            case let .momentMarked(t): return TranscriptLine(t: t, text: "(marked moment)")
            case let .userMark(a): return TranscriptLine(t: a.createdAt, text: "(drew on screen)")
            case .keyframe, .aiAnnotation: return nil
            }
        }
    }
}

public struct ReportContext: Sendable {
    public var appName: String
    public var startURL: String?
    public var startedAt: Date
    public var duration: Double
    public var mode: SessionMode
    public var transcript: [TranscriptLine]
    /// Keyed by 0-based item index.
    public var imageFiles: [Int: String]
    public var timeZone: TimeZone

    public init(appName: String, startURL: String?, startedAt: Date, duration: Double, mode: SessionMode,
                transcript: [TranscriptLine], imageFiles: [Int: String], timeZone: TimeZone = .current) {
        self.appName = appName
        self.startURL = startURL
        self.startedAt = startedAt
        self.duration = duration
        self.mode = mode
        self.transcript = transcript
        self.imageFiles = imageFiles
        self.timeZone = timeZone
    }
}

public enum MarkdownRenderer {
    public static func render(items: [FeedbackItem], context: ReportContext) -> String {
        let df = DateFormatter()
        df.locale = Locale(identifier: "en_US_POSIX")
        df.timeZone = context.timeZone
        df.dateFormat = "yyyy-MM-dd HH:mm"
        let secs = Int(context.duration.rounded())

        var out = "# Feedback: \(context.appName) — \(df.string(from: context.startedAt))\n"
        out += "Reviewed at: \(context.startURL ?? "unknown page") · \(secs / 60)m \(secs % 60)s · mode: \(context.mode.title)\n"

        if items.isEmpty {
            out += "\n_No feedback items were found in this session._\n"
        }
        for (i, item) in items.enumerated() {
            out += "\n## \(i + 1). \(item.title)\n"
            func line(_ label: String, _ value: String) {
                if !value.isEmpty { out += "- **\(label):** \(value)\n" }
            }
            line("Where", item.location)
            line("Problem", item.problem)
            line("Wanted", item.wanted)
            line("You said", item.quote.isEmpty ? "" : "\"\(item.quote)\"")
            if let file = context.imageFiles[i] {
                out += "- **Screenshot:** ![](\(file))" + (item.imageCaption.isEmpty ? "" : " — \(item.imageCaption)") + "\n"
            }
        }

        out += "\n---\n## Full transcript\n"
        for l in context.transcript {
            out += "[\(timestamp(l.t))] \(l.text)\n"
        }
        return out
    }

    public static func timestamp(_ t: Double) -> String {
        let s = max(0, Int(t))
        return String(format: "%02d:%02d", s / 60, s % 60)
    }
}

public enum HandoffPrompt {
    public static func make(folder: SessionFolder) -> String {
        var path = (folder.feedbackURL.path as NSString).abbreviatingWithTildeInPath
        if path.contains(" ") { path = "\"\(path)\"" }
        return "Read \(path) and the screenshots it links, then make each revision in this project. Ask me if an item is ambiguous."
    }
}

    case object([String: JSONValue])

        let c = try decoder.singleValueContainer()
        if c.decodeNil() { self = .null }

        else if let i = try? c.decode(Int.self) { self = .int(i) }

        case let .array(a): try c.encode(a)

import Foundation

public enum ContentBlock: Encodable, Equatable, Sendable {
    case text(String)
    case jpeg(Data)

    private enum Keys: String, CodingKey { case type, text, source }
    private struct Source: Encodable {
        let type = "base64"
        let media_type = "image/jpeg"
        let data: String
    }

    public func encode(to encoder: Encoder) throws {
        var c = encoder.container(keyedBy: Keys.self)
        switch self {
        case let .text(s):
            try c.encode("text", forKey: .type)
            try c.encode(s, forKey: .text)
        case let .jpeg(d):

        var r = URLRequest(url: Self.endpoint)
        r.httpMethod = "POST"
        r.timeoutInterval = 180
        r.setValue("application/json", forHTTPHeaderField: "content-type")
        r.setValue(apiKey, forHTTPHeaderField: "x-api-key")
        r.setValue(Self.apiVersion, forHTTPHeaderField: "anthropic-version")
        if request.fallbacks != nil {
            r.setValue(Self.fallbackBeta, forHTTPHeaderField: "anthropic-beta")
        }
        r.httpBody = try JSONEncoder().encode(request)
        return r
    }

    public func send(_ request: MessagesRequest) async throws -> MessagesResponse {
        let (data, response) = try await session.data(for: makeURLRequest(request))
        let status = (response as? HTTPURLResponse)?.statusCode ?? 0
        guard (200..<300).contains(status) else {
            throw ClaudeError.http(status: status, body: String(decoding: data, as: UTF8.self))
        }
        let decoded = try JSONDecoder().decode(MessagesResponse.self, from: data)
        switch decoded.stop_reason {
        case "refusal": throw ClaudeError.refusal
        case "max_tokens": throw ClaudeError.truncated
        default: return decoded
        }
    }
}

public struct ReportInput: Sendable {
    public var moments: [Moment]
    /// JPEG data keyed by moment id.
    public var images: [Int: Data]
    public var transcript: [TranscriptLine]
    public var startURL: String?

    public init(moments: [Moment], images: [Int: Data], transcript: [TranscriptLine], startURL: String?) {
        self.moments = moments
        self.images = images
        self.transcript = transcript
        self.startURL = startURL
    }

public enum ReportRequest {
    public static let systemPrompt = """
    You turn a recorded, spoken review of an app into a list of concrete revision requests. A coding agent \
    (Claude Code) will read your list and edit the app's source code, so each item must stand on its own.

    You receive numbered moments. Each has the reviewer's words, the page URL, and usually a screenshot. \
    Red marks on a screenshot are what the reviewer drew to point at something.

    - Merge moments that are about the same issue. Drop moments with no feedback in them (thinking aloud, \
    "ok, next page").
    - title: at most 8 words naming the change.
    - where: the route plus the UI element, e.g. "/settings/billing, the Current plan card".
    - problem: what is wrong, in the reviewer's terms.
    - wanted: the change they asked for. If they didn't say, give the most likely intent, starting with "Likely: ".
    - quote: the reviewer's most relevant words, verbatim.
    - image_caption: what the marks on the screenshot show, or "" if there are none.
    - moment_ids: the moments the item comes from.

    Use only what the reviewer said and what is visible. Don't invent requirements.
    """

    public static let schema: JSONValue = {
        func str() -> JSONValue { .object(["type": .string("string")]) }
        let item: JSONValue = .object([
            "type": .string("object"),
            "properties": .object([
                "title": str(),
                "moment_ids": .object(["type": .string("array"), "items": .object(["type": .string("integer")])]),
                "where": str(),
                "problem": str(),
                "wanted": str(),
                "quote": str(),
                "image_caption": str(),
            ]),
            "required": .array(["title", "moment_ids", "where", "problem", "wanted", "quote", "image_caption"].map(JSONValue.string)),
            "additionalProperties": .bool(false),
        ])
        return .object([
            "type": .string("object"),
            "properties": .object(["items": .object(["type": .string("array"), "items": item])]),
            "required": .array([.string("items")]),
            "additionalProperties": .bool(false),
        ])
    }()

    public static func make(model: String, input: ReportInput) -> MessagesRequest {
        var blocks: [ContentBlock] = [.text("Review started at: \(input.startURL ?? "unknown page")\n\nMoments follow.")]
        for m in input.moments {
            let header = "Moment \(m.id) [\(MarkdownRenderer.timestamp(m.start))–\(MarkdownRenderer.timestamp(m.end))]"
                + " on \(m.url ?? "unknown page")"
                + (m.userMarks.isEmpty ? "" : " (reviewer drew \(m.userMarks.count) mark(s))")
            blocks.append(.text("\(header)\nReviewer said: \(m.text.isEmpty ? "(nothing)" : m.text)"))
            if let jpeg = input.images[m.id] { blocks.append(.jpeg(jpeg)) }
        }
        let transcript = input.transcript.map { "[\(MarkdownRenderer.timestamp($0.t))] \($0.text)" }.joined(separator: "\n")
        blocks.append(.text("Full transcript with clicks and navigation:\n\(transcript)\n\nWrite the revision list."))

        return MessagesRequest(
            model: model,
            max_tokens: 16000,
            system: systemPrompt,
            messages: [.init(role: "user", content: blocks)],
            output_config: .init(effort: "medium", format: .init(schema: schema)),
            fallbacks: "default")
    }

    private struct Envelope: Decodable { var items: [FeedbackItem] }

    public static func parse(_ text: String, validMomentIDs: Set<Int>) throws -> [FeedbackItem] {
        let envelope: Envelope
        do {
            envelope = try JSONDecoder().decode(Envelope.self, from: Data(text.utf8))
        } catch {
            throw ClaudeError.invalidJSON(String(text.prefix(200)))
        }
        return envelope.items.compactMap { item in
            var item = item
            item.momentIDs = item.momentIDs.filter(validMomentIDs.contains)
            return item.title.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty ? nil : item
        }
    }
}

import CoreGraphics
import Foundation

public struct ReportResult: Equatable, Sendable {
    public var itemCount: Int
    public var usedAI: Bool
    public var prompt: String
    public var error: String?
    public var tokens: TokenUsage

    public init(itemCount: Int, usedAI: Bool, prompt: String, error: String?, tokens: TokenUsage) {
        self.itemCount = itemCount
        self.usedAI = usedAI
        self.prompt = prompt
        self.error = error
        self.tokens = tokens
    }
}

public protocol ReportBuilding: Sendable {
    func build(document: SessionDocument, folder: SessionFolder) async -> ReportResult
}

public struct ReportBuilder: ReportBuilding {
    public static let maxImages = 20
    public static let apiImageWidth = 1280
    public static let outputImageWidth = 2560

    private let llm: LLMClient?
    private let model: String
    private let timeZone: TimeZone

    public init(llm: LLMClient?, model: String, timeZone: TimeZone = .current) {
        self.llm = llm
        self.model = model
        self.timeZone = timeZone
    }

    public func build(document: SessionDocument, folder: SessionFolder) async -> ReportResult {
        let moments = MomentSegmenter.segment(document.events)
        let composed = composeImages(moments: moments, document: document, folder: folder)
        let transcript = TranscriptBuilder.lines(document.events)
        let startURL = document.events.lazy.compactMap { e -> String? in
            guard case let .urlChanged(url, _, _) = e else { return nil }
            return url
        }.first

        var items = FallbackReport.items(from: moments)
        var usedAI = false
        var errorText: String? = llm == nil ? "No API key set" : nil
        var tokens = TokenUsage()

        if let llm, !moments.isEmpty {
            let ids = composed.keys.sorted().prefix(Self.maxImages)
            var images: [Int: Data] = [:]
            for id in ids {
                if let jpeg = ImageFiles.jpegData(composed[id]!, maxWidth: Self.apiImageWidth) { images[id] = jpeg }
            }
            let input = ReportInput(moments: moments, images: images, transcript: transcript, startURL: startURL)
            do {
                let response = try await llm.send(ReportRequest.make(model: model, input: input))
                guard let text = response.firstText() else { throw ClaudeError.noText }
                items = try ReportRequest.parse(text, validMomentIDs: Set(moments.map(\.id)))
                usedAI = true
                tokens = TokenUsage(input: response.usage?.input_tokens ?? 0, output: response.usage?.output_tokens ?? 0)
            } catch {
                errorText = String(describing: error)
            }
        }

        var imageFiles: [Int: String] = [:]
        for (i, item) in items.enumerated() {
            guard let mid = item.momentIDs.first(where: { composed[$0] != nil }), let image = composed[mid] else { continue }
            let name = String(format: "%02d", i + 1) + "-" + Slug.make(item.title) + ".png"
            do {
                try ImageFiles.writePNG(ImageFiles.downscaled(image, maxWidth: Self.outputImageWidth), to: folder.url.appending(path: name))
                imageFiles[i] = name
            } catch {
                continue
            }
        }

        let duration = (document.metadata.endedAt ?? document.metadata.startedAt).timeIntervalSince(document.metadata.startedAt)
        let context = ReportContext(appName: SessionFolder.slug(fromURL: startURL), startURL: startURL,
                                    startedAt: document.metadata.startedAt, duration: duration, mode: document.metadata.mode,
                                    transcript: transcript, imageFiles: imageFiles, timeZone: timeZone)
        let markdown = MarkdownRenderer.render(items: items, context: context)
        do {
            try markdown.write(to: folder.feedbackURL, atomically: true, encoding: .utf8)
        } catch {
            errorText = "Couldn't write feedback.md: \(error.localizedDescription)"
        }

        return ReportResult(itemCount: items.count, usedAI: usedAI, prompt: HandoffPrompt.make(folder: folder),
                            error: errorText, tokens: tokens)
    }

    private func composeImages(moments: [Moment], document: SessionDocument, folder: SessionFolder) -> [Int: CGImage] {
        var out: [Int: CGImage] = [:]
        for m in moments {
            guard let kf = m.keyframe,
                  let raw = ImageFiles.load(folder.rawURL.appending(path: kf.file)),
                  let display = document.metadata.displays.first(where: { $0.id == kf.displayID }) else { continue }
            out[m.id] = AnnotationCompositor.compose(image: raw, display: display, annotations: m.userMarks + m.aiMarks) ?? raw
        }
        return out
    }
}

**Interfaces:**
- Consumes: `SessionFolder`, `SessionStore`, `SessionDocument`, `TimelineEvent`, `ReportBuilding`, `ReportResult` (Tasks 3, 8).
- Produces:
  - `struct SessionClock: Sendable { let startedAt: Date; init(startedAt: Date, now: @escaping @Sendable () -> Date = Date.init); func now() -> Double }`
  - `struct SessionContext { let folder: SessionFolder; let clock: SessionClock; let emit: @MainActor (TimelineEvent) -> Void }`
  - `@MainActor protocol SessionService: AnyObject { func start(context: SessionContext) async throws; func stop() async }`
  - `@MainActor protocol FrameCapturing: SessionService { var displays: [DisplayGeometry] { get }; func captureKeyframe(reason: KeyframeReason) async -> TimelineEvent? }`
  - `@MainActor @Observable final class SessionController` with `enum State { idle, recording(mode:startedAt:), finalizing, done(ReportResult), failed(String) }`, `state`, `lastFolder`, `isRecording`, `init(capture:services:outputRoot:reportBuilder:now:tickInterval:clickDelay:)`, `start(mode:) async`, `stop() async`, `cancel() async`, `handle(_:)`, `markMoment()`

Behavior:
- `start` creates `<root>/session-<date>/`, starts the capture service and then each other service in order, takes one initial keyframe, then every `tickInterval` takes a periodic keyframe and saves `session.json`.
- If any service fails to start, the already-started ones are stopped, the folder is removed, and the state becomes `.failed`.
- Events are accepted from start until the services have stopped. That way final sentences emitted during `stop()` are kept.
- Keyframes: a click waits `clickDelay`, then captures with reason `.click`. A sentence captures `.sentence`, a user mark `.pen`, and a moment mark `.mark`.
- `stop` stops the services in reverse order, renames the folder from the first URL, saves, builds the report, saves the token counts, and sets `.done`.
- `cancel` stops the services, deletes the folder, and sets `.idle`.

import Observation

public struct SessionClock: Sendable {
    public let startedAt: Date
    private let nowFn: @Sendable () -> Date

    public init(startedAt: Date, now: @escaping @Sendable () -> Date = Date.init) {
        self.startedAt = startedAt
        self.nowFn = now
    }

    /// Seconds since session start.
    public func now() -> Double { nowFn().timeIntervalSince(startedAt) }
}

public struct SessionContext {
    public let folder: SessionFolder
    public let clock: SessionClock
    public let emit: @MainActor (TimelineEvent) -> Void

    public init(folder: SessionFolder, clock: SessionClock, emit: @escaping @MainActor (TimelineEvent) -> Void) {
        self.folder = folder
        self.clock = clock
        self.emit = emit
    }
}

@MainActor public protocol SessionService: AnyObject {
    func start(context: SessionContext) async throws
    func stop() async
}

@MainActor public protocol FrameCapturing: SessionService {
    var displays: [DisplayGeometry] { get }
    func captureKeyframe(reason: KeyframeReason) async -> TimelineEvent?
}

@MainActor @Observable
public final class SessionController {
    public enum State: Equatable, Sendable {
        case idle
        case recording(mode: SessionMode, startedAt: Date)
        case finalizing
        case done(ReportResult)
        case failed(String)
    }

    public private(set) var state: State = .idle
    public private(set) var lastFolder: SessionFolder?

    @ObservationIgnored private let capture: any FrameCapturing
    @ObservationIgnored private let services: [any SessionService]
    @ObservationIgnored private let outputRoot: @MainActor () -> URL
    @ObservationIgnored private let reportBuilder: @MainActor () -> any ReportBuilding
    @ObservationIgnored private let now: @Sendable () -> Date
    @ObservationIgnored private let tickInterval: Duration
    @ObservationIgnored private let clickDelay: Duration

    @ObservationIgnored private var events: [TimelineEvent] = []
    @ObservationIgnored private var metadata: SessionMetadata?
    @ObservationIgnored private var folder: SessionFolder?
    @ObservationIgnored private var clock: SessionClock?
    @ObservationIgnored private var started: [any SessionService] = []
    @ObservationIgnored private var tickTask: Task<Void, Never>?
    @ObservationIgnored private var accepting = false

    public init(capture: any FrameCapturing, services: [any SessionService],
                outputRoot: @escaping @MainActor () -> URL,
                reportBuilder: @escaping @MainActor () -> any ReportBuilding,
                now: @escaping @Sendable () -> Date = Date.init,
                tickInterval: Duration = .seconds(5), clickDelay: Duration = .milliseconds(300)) {
        self.capture = capture
        self.services = services
        self.outputRoot = outputRoot
        self.reportBuilder = reportBuilder
        self.now = now
        self.tickInterval = tickInterval
        self.clickDelay = clickDelay
    }

    public var isRecording: Bool {
        if case .recording = state { return true }
        return false
    }

    public func start(mode: SessionMode) async {
        switch state {
        case .recording, .finalizing: return
        default: break
        }
        let date = now()
        let folder: SessionFolder
        do {
            folder = try SessionFolder.create(root: outputRoot(), slug: "session", date: date)
        } catch {
            state = .failed("Couldn't create the session folder: \(error.localizedDescription)")
            return
        }
        let clock = SessionClock(startedAt: date, now: now)
        self.folder = folder
        self.clock = clock
        events = []
        metadata = SessionMetadata(startedAt: date, endedAt: nil, mode: mode, displays: [], tokens: TokenUsage())
        accepting = true

        let context = SessionContext(folder: folder, clock: clock, emit: { [weak self] in self?.handle($0) })
        do {
            for service in [capture as any SessionService] + services {
                try await service.start(context: context)
                started.append(service)
            }
        } catch {
            accepting = false
            await stopStarted()
            try? FileManager.default.removeItem(at: folder.url)
            reset()
            state = .failed(error.localizedDescription)
            return
        }

        state = .recording(mode: mode, startedAt: date)
        await keyframe(.periodic)
        persist()

        let interval = tickInterval
        tickTask = Task { [weak self] in
            while !Task.isCancelled {
                try? await Task.sleep(for: interval)
                guard let self, self.isRecording else { return }
                await self.keyframe(.periodic)
                self.persist()
            }
        }
    }

    public func handle(_ event: TimelineEvent) {
        guard accepting else { return }
        events.append(event)
        guard isRecording else { return }

        let reason: KeyframeReason
        var delay: Duration = .zero
        switch event {
        case .click: reason = .click; delay = clickDelay
        case .sentence: reason = .sentence
        case .userMark: reason = .pen
        case .momentMarked: reason = .mark
        default: return
        }
        Task { [weak self] in
            if delay > .zero { try? await Task.sleep(for: delay) }
            await self?.keyframe(reason)
        }
    }

    public func markMoment() {
        guard isRecording, let clock else { return }
        handle(.momentMarked(t: clock.now()))
    }

    public func stop() async {
        guard isRecording, var folder, var metadata else { return }
        state = .finalizing
        tickTask?.cancel()
        tickTask = nil
        await stopStarted()   // services may still emit final events here
        accepting = false

        metadata.endedAt = now()
        metadata.displays = capture.displays
        let firstURL = events.lazy.compactMap { e -> String? in
            guard case let .urlChanged(url, _, _) = e else { return nil }
            return url
        }.first
        if let renamed = try? folder.renamed(slug: SessionFolder.slug(fromURL: firstURL), date: metadata.startedAt) {
            folder = renamed
        }
        self.folder = folder
        self.metadata = metadata
        persist()

        let result = await reportBuilder().build(document: document(), folder: folder)
        self.metadata?.tokens = result.tokens
        persist()
        lastFolder = folder
        reset()
        state = .done(result)
    }

    public func cancel() async {
        guard isRecording else { return }
        state = .finalizing
        tickTask?.cancel()
        tickTask = nil
        accepting = false
        await stopStarted()
        if let folder { try? FileManager.default.removeItem(at: folder.url) }
        reset()
        state = .idle
    }

    // MARK: - Private

    private func keyframe(_ reason: KeyframeReason) async {
        guard isRecording, let event = await capture.captureKeyframe(reason: reason), isRecording else { return }
        events.append(event)
    }

    private func stopStarted() async {
        for service in started.reversed() { await service.stop() }
        started = []
    }

    /// Only call while `metadata` is set (between start and reset).
    private func document() -> SessionDocument {
        SessionDocument(metadata: metadata!, events: events.sorted { $0.time < $1.time })
    }

    private func persist() {
        guard let folder, metadata != nil else { return }
        try? SessionStore.save(document(), to: folder)
    }

    private func reset() {
        folder = nil
        clock = nil
        metadata = nil
        events = []
    }
}

public struct ModifierFlags: OptionSet, Sendable {
    public let rawValue: Int
    public init(rawValue: Int) { self.rawValue = rawValue }
    public static let option = ModifierFlags(rawValue: 1 << 0)
    public static let control = ModifierFlags(rawValue: 1 << 1)
    public static let command = ModifierFlags(rawValue: 1 << 2)
    public static let shift = ModifierFlags(rawValue: 1 << 3)
    public static let function = ModifierFlags(rawValue: 1 << 4)
}

/// Turns raw modifier/key events into pen-down / pen-up. The pen is "hold ⌥ alone".
public struct PenGestureDetector: Sendable {
    public enum Output: Equatable, Sendable { case none, penDown, penUp }

    private enum Phase: Equatable, Sendable {
        case idle
        case pending(since: Double)
        case active
        case suppressed   // something else was pressed; wait until every modifier is released
    }

    public let holdDelay: Double
    private var phase: Phase = .idle

    public init(holdDelay: Double = 0.15) { self.holdDelay = holdDelay }

    public var isActive: Bool { phase == .active }
    public var isPending: Bool {
        if case .pending = phase { return true }
        return false
    }

    public mutating func flagsChanged(_ flags: ModifierFlags, at t: Double) -> Output {
        if flags.isEmpty {
            let wasActive = phase == .active
            phase = .idle
            return wasActive ? .penUp : .none
        }
        switch phase {
        case .idle:
            phase = flags == .option ? .pending(since: t) : .suppressed
            return .none
        case .pending:
            if flags != .option { phase = .suppressed }
            return .none
        case .active:
            if flags != .option {
                phase = .suppressed
                return .penUp
            }
            return .none
        case .suppressed:
            return .none
        }
    }

    public mutating func keyDown(at t: Double) -> Output {
        switch phase {
        case .pending:
            phase = .suppressed
            return .none
        case .active:
            phase = .suppressed
            return .penUp
        default:
            return .none
        }
    }

    public mutating func tick(at t: Double) -> Output {
        if case let .pending(since) = phase, t - since >= holdDelay {
            phase = .active
            return .penDown
        }
        return .none
    }
}

import Foundation
import Security

enum KeychainStore {
    static let service = "com.dmschellaz.redline"
    static let account = "anthropic-api-key"

    private static var baseQuery: [String: Any] {
        [kSecClass as String: kSecClassGenericPassword,
         kSecAttrService as String: service,
         kSecAttrAccount as String: account]
    }

    static func save(_ key: String) throws {
        delete()
        var query = baseQuery
        query[kSecValueData as String] = Data(key.utf8)
        let status = SecItemAdd(query as CFDictionary, nil)
        guard status == errSecSuccess else { throw NSError(domain: NSOSStatusErrorDomain, code: Int(status)) }
    }

    static func load() -> String? {
        var query = baseQuery
        query[kSecReturnData as String] = true
        query[kSecMatchLimit as String] = kSecMatchLimitOne
        var out: CFTypeRef?
        guard SecItemCopyMatching(query as CFDictionary, &out) == errSecSuccess, let data = out as? Data else { return nil }
        return String(data: data, encoding: .utf8)
    }

    static func delete() {
        SecItemDelete(baseQuery as CFDictionary)
    }
}

enum Permission: String, CaseIterable, Identifiable {
    case screenRecording, microphone, speech, inputMonitoring

    var id: String { rawValue }

    var title: String {
        switch self {
        case .screenRecording: "Screen Recording"
        case .microphone: "Microphone"
        case .speech: "Speech Recognition"
        case .inputMonitoring: "Input Monitoring"
        }
    }

    var reason: String {
        switch self {
        case .screenRecording: "Takes screenshots of the app you're reviewing."
        case .microphone: "Hears your narration. Audio is never saved."
        case .speech: "Turns your narration into text on this Mac."
        case .inputMonitoring: "Notices clicks and the ⌥ pen key while you record."
        }
    }

    var settingsURL: URL {
        let anchor = switch self {
        case .screenRecording: "Privacy_ScreenCapture"
        case .microphone: "Privacy_Microphone"
        case .speech: "Privacy_SpeechRecognition"
        case .inputMonitoring: "Privacy_ListenEvent"
        }
        return URL(string: "x-apple.systempreferences:com.apple.preference.security?\(anchor)")!
    }

    @MainActor var isGranted: Bool {
        switch self {
        case .screenRecording: CGPreflightScreenCaptureAccess()
        case .microphone: AVCaptureDevice.authorizationStatus(for: .audio) == .authorized
        case .speech: SFSpeechRecognizer.authorizationStatus() == .authorized
        case .inputMonitoring: CGPreflightListenEventAccess()
        }
    }

        switch self {
        case .screenRecording:
            _ = CGRequestScreenCaptureAccess()
        case .microphone:
            _ = await AVCaptureDevice.requestAccess(for: .audio)
        case .speech:
            await withCheckedContinuation { (c: CheckedContinuation<Void, Never>) in
                SFSpeechRecognizer.requestAuthorization { _ in c.resume() }
            }
        case .inputMonitoring:
            _ = CGRequestListenEventAccess()
        }
        if !isGranted { NSWorkspace.shared.open(settingsURL) }
    }

    @MainActor static var missing: [Permission] { allCases.filter { !$0.isGranted } }

    private var context: SessionContext?

        self.context = context
        _ = try await refresh()   // fails fast if Screen Recording isn't granted

    func captureKeyframe(reason: KeyframeReason) async -> TimelineEvent? {
        guard let context else { return nil }
        do {
            let content = try await refresh()
            let cursor = CoordinateMapper.quartz(fromCocoa: NSEvent.mouseLocation, primaryHeight: primaryScreenHeight())
            guard let geo = CoordinateMapper.display(containing: cursor, in: displays) ?? displays.first,
                  let scDisplay = content.displays.first(where: { $0.displayID == geo.id }) else { return nil }

            let ownApps = content.applications.filter { $0.bundleIdentifier == Bundle.main.bundleIdentifier }
            let filter = SCContentFilter(display: scDisplay, excludingApplications: ownApps, exceptingWindows: [])
            let config = SCStreamConfiguration()
            config.width = Int(geo.frame.width * geo.scale)
            config.height = Int(geo.frame.height * geo.scale)
            config.showsCursor = true

            let t = context.clock.now()
            let image = try await SCScreenshotManager.captureImage(contentFilter: filter, configuration: config)
            let file = "kf-\(Int(t * 1000))-\(reason.rawValue).png"
            try ImageFiles.writePNG(image, to: context.folder.rawURL.appending(path: file))
            return .keyframe(KeyframeRef(id: UUID(), file: file, t: t, displayID: geo.id), reason: reason)
        } catch {
            NSLog("Redline: capture failed: \(error)")
            return nil
        }

        let content = try await SCShareableContent.excludingDesktopWindows(false, onScreenWindowsOnly: true)
        displays = content.displays.map { d in
            let bounds = CGDisplayBounds(d.displayID)
            let scale = CGDisplayCopyDisplayMode(d.displayID).map { Double($0.pixelWidth) / Double($0.width) } ?? 2
            return DisplayGeometry(id: d.displayID, frame: bounds, scale: scale)

    }

import AVFoundation
import CoreMedia
import RedlineCore
import Speech

/// Converts mic buffers to the analyzer's format on the audio thread.
private final class AudioPipe: @unchecked Sendable {
    let converter: AVAudioConverter
    let outFormat: AVAudioFormat
    let continuation: AsyncStream<AnalyzerInput>.Continuation

    init?(from inFormat: AVAudioFormat, to outFormat: AVAudioFormat, continuation: AsyncStream<AnalyzerInput>.Continuation) {
        guard let converter = AVAudioConverter(from: inFormat, to: outFormat) else { return nil }
        self.converter = converter
        self.outFormat = outFormat
        self.continuation = continuation
    }

    func push(_ buffer: AVAudioPCMBuffer) {
        let ratio = outFormat.sampleRate / buffer.format.sampleRate
        let capacity = AVAudioFrameCount(Double(buffer.frameLength) * ratio) + 1024
        guard let out = AVAudioPCMBuffer(pcmFormat: outFormat, frameCapacity: capacity) else { return }
        var fed = false
        var error: NSError?
        converter.convert(to: out, error: &error) { _, status in
            if fed {
                status.pointee = .noDataNow
                return nil
            }
            fed = true
            status.pointee = .haveData
            return buffer
        }
        if error == nil, out.frameLength > 0 {
            continuation.yield(AnalyzerInput(buffer: out))
        }
    }
}

enum SpeechServiceError: LocalizedError {
    case noAudioFormat, converterUnavailable
    var errorDescription: String? {
        switch self {
        case .noAudioFormat: "Speech recognition isn't available for this language."
        case .converterUnavailable: "Couldn't read the microphone."
        }
    }
}

@MainActor
final class SpeechService: SessionService {
    var onPartial: (@MainActor (String) -> Void)?

    private let engine = AVAudioEngine()
    private var analyzer: SpeechAnalyzer?
    private var continuation: AsyncStream<AnalyzerInput>.Continuation?
    private var resultsTask: Task<Void, Never>?

    func start(context: SessionContext) async throws {
        let locale = await SpeechTranscriber.supportedLocale(equivalentTo: Locale.current) ?? Locale(identifier: "en-US")
        let transcriber = SpeechTranscriber(locale: locale, transcriptionOptions: [],
                                            reportingOptions: [.volatileResults], attributeOptions: [.audioTimeRange])
        if let install = try await AssetInventory.assetInstallationRequest(supporting: [transcriber]) {
            try await install.downloadAndInstall()   // first run only: downloads the on-device model
        }
        guard let format = await SpeechAnalyzer.bestAvailableAudioFormat(compatibleWith: [transcriber]) else {
            throw SpeechServiceError.noAudioFormat
        }

        let analyzer = SpeechAnalyzer(modules: [transcriber])
        let (stream, continuation) = AsyncStream<AnalyzerInput>.makeStream()
        let offset = context.clock.now()
        let emit = context.emit

        resultsTask = Task { [weak self] in
            do {
                for try await result in transcriber.results {
                    let text = String(result.text.characters).trimmingCharacters(in: .whitespacesAndNewlines)
                    if result.isFinal {
                        self?.onPartial?("")
                        guard !text.isEmpty else { continue }
                        emit(.sentence(id: UUID(), text: text,
                                       start: offset + result.range.start.seconds,
                                       end: offset + result.range.end.seconds))
                    } else {
                        self?.onPartial?(text)
                    }
                }
            } catch {
                NSLog("Redline: transcription ended: \(error)")
            }
        }

        try await analyzer.start(inputSequence: stream)

        let input = engine.inputNode
        let inFormat = input.outputFormat(forBus: 0)
        guard let pipe = AudioPipe(from: inFormat, to: format, continuation: continuation) else {
            throw SpeechServiceError.converterUnavailable
        }
        input.installTap(onBus: 0, bufferSize: 4096, format: inFormat) { buffer, _ in pipe.push(buffer) }
        engine.prepare()
        try engine.start()

        self.analyzer = analyzer
        self.continuation = continuation
    }

    func stop() async {
        engine.inputNode.removeTap(onBus: 0)
        engine.stop()
        continuation?.finish()
        try? await analyzer?.finalizeAndFinishThroughEndOfInput()
        await resultsTask?.value
        analyzer = nil
        continuation = nil
        resultsTask = nil
        onPartial?("")
    }
}
```

import AppKit

enum BrowserURLReader {
    private static let scripts: [String: String] = [
        "com.google.Chrome": #"tell application id "com.google.Chrome" to get {URL, title} of active tab of front window"#,
        "company.thebrowser.Browser": #"tell application id "company.thebrowser.Browser" to get {URL, title} of active tab of front window"#,
        "com.apple.Safari": #"tell application id "com.apple.Safari" to get {URL, name} of front document"#,
    ]

    static func supports(_ bundleID: String) -> Bool { scripts[bundleID] != nil }

    /// Returns nil for unsupported apps, no window, or denied Automation permission.
    @MainActor static func read(bundleID: String) -> (url: String, title: String?)? {
        guard let source = scripts[bundleID], let script = NSAppleScript(source: source) else { return nil }
        var error: NSDictionary?
        let result = script.executeAndReturnError(&error)
        guard error == nil, result.numberOfItems >= 1, let url = result.atIndex(1)?.stringValue, !url.isEmpty else { return nil }
        return (url, result.atIndex(2)?.stringValue)
    }

import AppKit
import RedlineCore

enum ContextServiceError: LocalizedError {
    case eventTapUnavailable
    var errorDescription: String? { "Redline needs Input Monitoring permission to notice clicks and the pen key." }
}

@MainActor
final class ContextService: SessionService {
    var onPen: (@MainActor (Bool) -> Void)?

    private var tap: CFMachPort?
    private var source: CFRunLoopSource?
    private var detector = PenGestureDetector()
    private var urlTimer: Timer?
    private var lastURL: String?
    private var context: SessionContext?

    func start(context: SessionContext) async throws {
        self.context = context
        lastURL = nil
        detector = PenGestureDetector()

        let mask = (1 << CGEventType.leftMouseDown.rawValue)
            | (1 << CGEventType.flagsChanged.rawValue)
            | (1 << CGEventType.keyDown.rawValue)
        let refcon = Unmanaged.passUnretained(self).toOpaque()
        guard let tap = CGEvent.tapCreate(
            tap: .cgSessionEventTap, place: .headInsertEventTap, options: .listenOnly,
            eventsOfInterest: CGEventMask(mask),
            callback: { _, type, event, refcon in
                guard let refcon else { return Unmanaged.passUnretained(event) }
                let service = Unmanaged<ContextService>.fromOpaque(refcon).takeUnretainedValue()
                let location = event.location
                let flags = event.flags
                MainActor.assumeIsolated { service.handle(type: type, location: location, flags: flags) }
                return Unmanaged.passUnretained(event)
            },
            userInfo: refcon) else { throw ContextServiceError.eventTapUnavailable }

        self.tap = tap
        source = CFMachPortCreateRunLoopSource(nil, tap, 0)
        CFRunLoopAddSource(CFRunLoopGetMain(), source, .commonModes)
        CGEvent.tapEnable(tap: tap, enable: true)

        urlTimer = Timer.scheduledTimer(withTimeInterval: 1, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.pollURL() }
        }
        pollURL()
    }

    func stop() async {
        urlTimer?.invalidate()
        urlTimer = nil
        if let tap { CGEvent.tapEnable(tap: tap, enable: false) }
        if let source { CFRunLoopRemoveSource(CFRunLoopGetMain(), source, .commonModes) }
        tap = nil
        source = nil
        if detector.isActive { onPen?(false) }
        context = nil
    }

    private func handle(type: CGEventType, location: CGPoint, flags: CGEventFlags) {
        guard let context else { return }
        let t = context.clock.now()
        switch type {
        case .tapDisabledByTimeout, .tapDisabledByUserInput:
            if let tap { CGEvent.tapEnable(tap: tap, enable: true) }
        case .leftMouseDown:
            guard !detector.isActive else { return }
            var displayID: CGDirectDisplayID = 0
            var count: UInt32 = 0
            CGGetDisplaysWithPoint(location, 1, &displayID, &count)
            context.emit(.click(point: location, displayID: displayID, t: t))
            DispatchQueue.main.asyncAfter(deadline: .now() + 0.6) { [weak self] in
                MainActor.assumeIsolated { self?.pollURL() }
            }
        case .flagsChanged:
            apply(detector.flagsChanged(Self.modifiers(flags), at: t))
            if detector.isPending {
                DispatchQueue.main.asyncAfter(deadline: .now() + detector.holdDelay + 0.01) { [weak self] in
                    MainActor.assumeIsolated {
                        guard let self, let clock = self.context?.clock else { return }
                        self.apply(self.detector.tick(at: clock.now()))
                    }
                }
            }
        case .keyDown:
            apply(detector.keyDown(at: t))
        default:
            break
        }
    }

    private func apply(_ output: PenGestureDetector.Output) {
        switch output {
        case .penDown: onPen?(true)
        case .penUp: onPen?(false)
        case .none: break
        }
    }

    private func pollURL() {
        guard let context,
              let bundleID = NSWorkspace.shared.frontmostApplication?.bundleIdentifier,
              BrowserURLReader.supports(bundleID),
              let page = BrowserURLReader.read(bundleID: bundleID),
              page.url != lastURL else { return }
        lastURL = page.url
        context.emit(.urlChanged(url: page.url, title: page.title, t: context.clock.now()))
    }

    private static func modifiers(_ f: CGEventFlags) -> ModifierFlags {
        var m: ModifierFlags = []
        if f.contains(.maskAlternate) { m.insert(.option) }
        if f.contains(.maskControl) { m.insert(.control) }
        if f.contains(.maskCommand) { m.insert(.command) }
        if f.contains(.maskShift) { m.insert(.shift) }
        if f.contains(.maskSecondaryFn) { m.insert(.function) }
        return m
    }
}

import RedlineCore
import SwiftUI

struct ShownMark: Identifiable {
    let annotation: Annotation
    let shownAt: Date
    let lifetime: Double
    var id: UUID { annotation.id }
}

@MainActor @Observable
final class OverlayModel {
    let display: DisplayGeometry
    var marks: [ShownMark] = []
    var liveStroke: [CGPoint] = []   // local points
    var penActive = false
    init(display: DisplayGeometry) { self.display = display }
}

struct OverlayView: View {
    @Bindable var model: OverlayModel
    let onStroke: ([CGPoint]) -> Void

    var body: some View {
        TimelineView(.animation(paused: model.marks.isEmpty && model.liveStroke.isEmpty)) { timeline in
            Canvas { gc, _ in
                for mark in model.marks {
                    let remaining = mark.lifetime - timeline.date.timeIntervalSince(mark.shownAt)
                    let alpha = max(0, min(1, remaining / 0.6))
                    guard alpha > 0 else { continue }
                    let local = mark.annotation.shape.mapped({ CoordinateMapper.local(fromGlobal: $0, on: model.display) }, lengthScale: 1)
                    draw(local, in: &gc, color: mark.annotation.author == .user ? Color(cgColor: Palette.user) : Color(cgColor: Palette.ai), alpha: alpha)
                }
                if model.liveStroke.count > 1 {
                    draw(.stroke(model.liveStroke), in: &gc, color: Color(cgColor: Palette.user), alpha: 1)
                }
            }
        }
        // A faint tint while drawing: it shows pen mode and makes the window catch clicks (fully clear pixels pass through).
        .background(model.penActive ? Color.black.opacity(0.04) : Color.clear)
        .contentShape(Rectangle())
        .gesture(
            DragGesture(minimumDistance: 0, coordinateSpace: .local)
                .onChanged { value in if model.penActive { model.liveStroke.append(value.location) } }
                .onEnded { _ in
                    if model.liveStroke.count > 1 { onStroke(model.liveStroke) }
                    model.liveStroke = []
                }
        )
    }

    private func draw(_ shape: AnnotationShape, in gc: inout GraphicsContext, color: Color, alpha: Double) {
        let style = StrokeStyle(lineWidth: 4, lineCap: .round, lineJoin: .round)
        let c = color.opacity(alpha)
        switch shape {
        case let .circle(center, r):
            gc.stroke(Path(ellipseIn: CGRect(x: center.x - r, y: center.y - r, width: 2 * r, height: 2 * r)), with: .color(c), style: style)
        case let .rect(r):
            gc.stroke(Path(roundedRect: r, cornerRadius: 6), with: .color(c), style: style)
        case let .highlight(r):
            gc.fill(Path(roundedRect: r, cornerRadius: 4), with: .color(Color(cgColor: Palette.highlight).opacity(alpha)))
        case let .arrow(from, to):
            var p = Path()
            p.move(to: from)
            p.addLine(to: to)
            let angle = atan2(to.y - from.y, to.x - from.x)
            for side in [-1.0, 1.0] {
                let a = angle + .pi + side * .pi / 7
                p.move(to: to)
                p.addLine(to: CGPoint(x: to.x + 14 * cos(a), y: to.y + 14 * sin(a)))
            }
            gc.stroke(p, with: .color(c), style: style)
        case let .stroke(points):
            var p = Path()
            p.addLines(points)
            gc.stroke(p, with: .color(c), style: style)
        }
    }

import AppKit
import RedlineCore
import SwiftUI

@MainActor
final class OverlayController: SessionService {
    private var panels: [(panel: NSPanel, model: OverlayModel)] = []
    private var context: SessionContext?

    func start(context: SessionContext) async throws {
        self.context = context
        showPanels()
    }

    func stop() async {
        setPen(false)
        for p in panels { p.panel.orderOut(nil) }
        panels = []
        context = nil
    }

    func setPen(_ active: Bool) {
        let cursor = CoordinateMapper.quartz(fromCocoa: NSEvent.mouseLocation, primaryHeight: primaryScreenHeight())
        for p in panels {
            let on = active && p.model.display.frame.contains(cursor)
            p.model.penActive = on
            p.panel.ignoresMouseEvents = !on
            if !on { p.model.liveStroke = [] }
        }
        (active ? NSCursor.crosshair : NSCursor.arrow).set()
    }

    func display(_ annotation: Annotation, lifetime: Double) {
        guard let p = panels.first(where: { $0.model.display.id == annotation.displayID }) else { return }
        p.model.marks.append(ShownMark(annotation: annotation, shownAt: Date(), lifetime: lifetime))
        DispatchQueue.main.asyncAfter(deadline: .now() + lifetime + 0.1) { [weak model = p.model] in
            MainActor.assumeIsolated { model?.marks.removeAll { $0.id == annotation.id } }
        }
    }

    private func showPanels() {
        for screen in NSScreen.screens {
            guard let id = screen.displayID else { continue }
            let geo = DisplayGeometry(id: id, frame: CGDisplayBounds(id), scale: screen.backingScaleFactor)
            let model = OverlayModel(display: geo)
            let panel = NSPanel(contentRect: screen.frame, styleMask: [.borderless, .nonactivatingPanel], backing: .buffered, defer: false)
            panel.isOpaque = false
            panel.backgroundColor = .clear
            panel.hasShadow = false
            panel.level = .screenSaver
            panel.collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary, .ignoresCycle]
            panel.ignoresMouseEvents = true
            panel.contentView = NSHostingView(rootView: OverlayView(model: model) { [weak self] points in
                self?.finishStroke(points, on: geo)
            })
            panel.setFrame(screen.frame, display: true)
            panel.orderFrontRegardless()
            panels.append((panel, model))
        }
    }

    private func finishStroke(_ local: [CGPoint], on geo: DisplayGeometry) {
        let global = local.map { CoordinateMapper.global(fromLocal: $0, on: geo) }
        let annotation = Annotation(shape: .stroke(global), caption: nil, author: .user,
                                    createdAt: context?.clock.now() ?? 0, displayID: geo.id)
        display(annotation, lifetime: 4)
        context?.emit(.userMark(annotation))
    }
}

final class NotificationDelegate: NSObject, UNUserNotificationCenterDelegate {

        -> UNNotificationPresentationOptions { [.banner, .sound] }

}

@MainActor

    private static let delegate = NotificationDelegate()

    static func setUp() {

        center.delegate = delegate
        center.requestAuthorization(options: [.alert, .sound]) { _, _ in }
    }

    static func post(title: String, body: String, folder: URL?) {
        let content = UNMutableNotificationContent()
        content.title = title
        content.body = body
        if let folder { content.userInfo = ["folder": folder.path] }
        UNUserNotificationCenter.current().add(UNNotificationRequest(identifier: UUID().uuidString, content: content, trigger: nil))

import AppKit
import KeyboardShortcuts
import Observation
import RedlineCore

@MainActor @Observable
final class AppModel {
    let settings = AppSettings()
    private(set) var partialTranscript = ""
    @ObservationIgnored private(set) var controller: SessionController!

    @ObservationIgnored private let capture = CaptureService()
    @ObservationIgnored private let overlay = OverlayController()
    @ObservationIgnored private let context = ContextService()
    @ObservationIgnored private let speech = SpeechService()
    @ObservationIgnored private let pill = RecordingPillController()
    @ObservationIgnored private let onboarding = OnboardingWindowController()

    var isRecording: Bool { controller.isRecording }
    var isFinalizing: Bool { controller.state == .finalizing }
    var lastSessionFolder: URL? { settings.lastSessionPath.map { URL(fileURLWithPath: $0) } }

    init() {
        let settings = self.settings
        controller = SessionController(
            capture: capture,
            services: [overlay, context, speech],   // stop order is reversed: speech flushes first
            outputRoot: { settings.outputRoot },
            reportBuilder: { Self.makeReportBuilder(settings) })
        context.onPen = { [overlay] in overlay.setPen($0) }
        speech.onPartial = { [weak self] in self?.partialTranscript = $0 }
    }

    func launch() {
        Notifier.setUp()
        KeyboardShortcuts.onKeyUp(for: .toggleSession) { [weak self] in Task { @MainActor in await self?.toggleSession() } }
        KeyboardShortcuts.onKeyUp(for: .markMoment) { [weak self] in Task { @MainActor in self?.markMoment() } }
        if !Permission.missing.isEmpty { onboarding.show() }
    }

    func toggleSession() async {
        switch controller.state {
        case .recording: await stopSession()
        case .finalizing: return
        default: await startSession()
        }
    }

    func cancel() async {
        await controller.cancel()
        pill.hide()
        partialTranscript = ""
    }

    func markMoment() {
        guard isRecording else { return }
        controller.markMoment()
        NSSound(named: "Tink")?.play()
    }

    func showOnboarding() { onboarding.show() }

    func regenerateLast() async {
        guard let url = lastSessionFolder else { return }
        let folder = SessionFolder(url: url)
        do {
            let doc = try SessionStore.load(from: folder)
            let result = await Self.makeReportBuilder(settings).build(document: doc, folder: folder)
            handOff(result, folder: folder)
        } catch {
            Notifier.post(title: "Couldn't regenerate", body: error.localizedDescription, folder: url)
        }
    }

    func recentSessions(limit: Int = 5) -> [URL] {
        let fm = FileManager.default
        let urls = (try? fm.contentsOfDirectory(at: settings.outputRoot, includingPropertiesForKeys: [.contentModificationDateKey],
                                                 options: [.skipsHiddenFiles])) ?? []
        return urls
            .filter { fm.fileExists(atPath: $0.appending(path: "session.json").path) }
            .sorted {
                let a = (try? $0.resourceValues(forKeys: [.contentModificationDateKey]).contentModificationDate) ?? .distantPast
                let b = (try? $1.resourceValues(forKeys: [.contentModificationDateKey]).contentModificationDate) ?? .distantPast
                return a > b
            }
            .prefix(limit).map { $0 }
    }

    // MARK: - Private

    private func startSession() async {
        guard Permission.missing.isEmpty else {
            onboarding.show()
            return
        }
        pill.show(model: self)
        await controller.start(mode: .manual)
        if case let .failed(message) = controller.state {
            pill.hide()
            Notifier.post(title: "Couldn't start recording", body: message, folder: nil)
            return
        }
        NSSound(named: "Pop")?.play()
    }

    private func stopSession() async {
        await controller.stop()
        pill.hide()
        partialTranscript = ""
        if case let .done(result) = controller.state, let folder = controller.lastFolder {
            handOff(result, folder: folder)
        }
    }

    private func handOff(_ result: ReportResult, folder: SessionFolder) {
        NSPasteboard.general.clearContents()
        NSPasteboard.general.setString(result.prompt, forType: .string)
        settings.lastSessionPath = folder.url.path
        let body = result.usedAI
            ? "\(result.itemCount) item\(result.itemCount == 1 ? "" : "s") copied. Paste into Claude Code."
            : "Saved without an AI write-up (\(result.error ?? "unknown error")). Prompt copied."
        Notifier.post(title: "Feedback ready", body: body, folder: folder.url)
    }

    private static func makeReportBuilder(_ settings: AppSettings) -> any ReportBuilding {
        ReportBuilder(llm: settings.apiKey().map { ClaudeHTTPClient(apiKey: $0) }, model: settings.reportModel)
    }
}
